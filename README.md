## 📌 Run Locally

Want to explore the portfolio on your own machine?

1. Clone the repository:

   ```bash
   git clone https://github.com/falakmunir7-code/falak-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd falak-portfolio
   ```

3. Open `index.html` in your browser.

**Note:** Keep the `videos` folder alongside `index.html` so the background video can load correctly. The video file must also be included when deploying the website.
